Structure loot editor

Set loot tables on the chests inside a Bedrock .mcstructure file. It reads the compressed format from 26.60 as well as older files. Your file is processed in this browser and is never uploaded.

Drop a .mcstructure file here

or choose one from your computer.

This file doesn't re-save byte for byte. Saving it with no edits would change it slightly. The edits are probably still fine, but test the result in a world before you ship it.
